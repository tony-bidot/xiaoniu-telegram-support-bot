# 小牛VPN Support Intents

这份文件用来整理当前高频客服场景，方便后续：
- 调整 FAQ
- 优化 `bot.py` 路由逻辑
- 编写测试用例
- 未来迁移到独立 `xiaoniu-support` agent

---

## 1. Greeting / 开场

### intent id
`greeting`

### 用户常见说法
- 你好
- hi
- hello
- 在吗
- 有人吗
- 哈喽

### 期望处理
- 直接回复在场、可协助
- 不进入故障排查
- 不进入下载/节点/FAQ 误命中

### 当前目标回复方向
- 你好，我在的
- 可以直接发下载、登录、连接、掉线、节点使用等问题

---

## 2. 模糊求助

### intent id
`vague_help`

### 用户常见说法
- 我有问题
- 有点问题
- 出问题了
- 帮我看看
- 帮忙看下
- 用不了

### 期望处理
- 不要直接跳到平台下载链接
- 不要直接判断成某种故障
- 自然追问用户具体情况

### 当前目标回复方向
- 请用户直接描述问题
- 可顺手提示带上设备类型、截图、节点名称

## 3. 支持平台 / 使用能力

- mac能用吗

## 4. AI 平台支持类

### intent id
`ai_platform_support`

- 哪些节点支持AI
- ChatGPT能用吗

### 当前目标回复方向

- 优先尝试香港、日本、美国

## 5. AI 节点故障类

### intent id
`ai_node_issue`

### 用户常见说法
- AI节点用不了
- AI节点不能用
- Gemini用不了
- 解锁不了Gemini
- AI节点不正常

### 期望处理
- 识别为故障，不是支持性提问
- 建议先切换其他可用节点
- 如为个别节点问题，记录并让工程师跟进
- 可追问节点名称、设备类型、截图

### 当前目标回复方向
- 先切换其他节点试
- 这边记录问题，工程师继续跟进

## 7. 流媒体节点故障类

## 15. 下载 / 安装

### intent id
- `android_download`
- `windows_download`
- `mac_download`
- `ios_download`
- `download_failed`
- `install_failed`
- `regular_vs_speed_edition`

### 关键事实
- Windows 仅支持 Win10 及以上
- Windows 下载地址必须保持：
  `https://q1w2e3r4.xyz/android/aoxlite-v7.0.0.exe`
- iOS 目前没有正式上架版本，仅提供 TestFlight 版本，正式上架版本仍在准备中
- 所有平台目前都分为常规版和极速版
- 极速版是采用新技术更新的版本，只保留核心 VPN 功能
- 如果常规版不稳定，建议优先尝试极速版
- Windows 虚拟网卡：`utun99`
- Mac 虚拟网卡：`tun0`

## 16. VIP / 免费 / 购买

### intent id
- `plans`
- `vip_vs_free`
- `become_vip`

### 关键事实
- VIP 套餐选择请直接前往官网详细查询
- VIP 用户可解锁大量高质量节点，并且不限速
- 免费用户速度相对较慢，可使用节点也比较有限
- 如需成为 VIP，请直接前往官网购买

## 18. 通用推荐节点（重要）

### 推荐节点
- 香港节点
- 日本节点
- 美国节点

### 使用原则
这些节点不是仅限某一类场景，而是当前的**通用优先推荐节点**。

### 适用场景
- AI 平台
- 流媒体
- 节点不稳定
- 速度慢
- 一般切换节点建议

### 推荐原因
- 通常速度更快
- 节点数量更多

---

## 19. 当前仍需持续观察的风险点

- 支持性提问 vs 故障性提问仍可能混淆
- 短补充句（如“解锁不了”“美国1节点”）仍需要持续测试
- 多轮连续消息时，要避免 fallback 插入
- 节点名插入文案要保持自然
